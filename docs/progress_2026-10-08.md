## Models (all on `Jinyan0924/qwen_robotics_nav_policy`, public; Qwen3.5-4B-Base + LoRA rank 32)

| Run | Inputs | v3 success / completed / collided / ADE / FDE |
|---|---|---|
| constant velocity (baseline) | - | 0.33 / 0.38 / 0.24 / 0.84 / 1.92 |
| `ff3_lora4b_dedup` (step 4,000) | past frames + frame 5 s ahead | 0.43 / 0.54 / 0.27 / 0.70 / 1.25 |
| `ff4_lora4b_instruction` (step 6,000) | past frames + task text (description, place, interaction) | 0.56 / 0.69 / 0.21 / 0.53 / 0.82 |
| `ff5_lora4b_instruction_camera` (step 6,000) | ff4 + camera sentence | 0.57 / 0.71 / 0.21 / 0.53 / 0.82 |

- ff3 is the first model that reads the final frame (swapping it moves the end point 2.6 m).
- ff4 / ff5 steer by the text (with another scenario's text success drops to about 0.1). The text states the
  outcome, so these numbers measure text following plus avoidance, not unaided navigation.
- The camera sentence (field of view, height from stored calibration, else "unknown") has no effect: the model ignores
  it. Owner: fine, no debugging.

## How to run

```bash
bash scripts/launch_run.sh <run> <steps> 4b-lora <final_frame|instruction|instruction_camera> [--min-path-m 2.0 ...]
```
Training + milestone watcher in one command, resumable; `--init-from hub:<repo>/<run>/<folder>` to start from a checkpoint.
