# Licence of the evaluation suite

The suite is a selection of scenarios converted from four datasets. Each scenario keeps the licence of the
dataset it comes from (column `source`); all of them allow non-commercial use only.

| `source` | Dataset | Licence |
|---|---|---|
| `coda` | UT Campus Object Dataset (CODa) | CC BY-NC-SA 4.0 |
| `jrdb` | JackRabbot Dataset and Benchmark (JRDB) | CC BY-NC-SA 3.0 |
| `robosense` | RoboSense | CC BY-NC-SA 4.0 (the stricter of the source's README and Hub tag) |
| `hssd` | Habitat Synthetic Scenes Dataset (HSSD), rendered with habitat-sim | CC BY-NC 4.0 |

Share-alike terms apply to the CODa, JRDB and RoboSense scenarios. The selection, goals, prompts, tags and audit
are released under the same terms. Cite the source datasets when you use the suite.
